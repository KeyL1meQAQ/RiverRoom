# 牌桌行动音效

状态：Q1–Q9 及完整方案已确认；实现和本地自动化验证完成，实际听感待用户试听。未提交、推送或部署。

## 已确认的声音与范围

| 场景 | 声音 | 听众 |
| --- | --- | --- |
| 下注、跟注、加注、全下 | 短促的真实筹码碰撞声 | 包括操作者及观战者在内的房间参与者 |
| 手动过牌、超时自动过牌 | 清楚的两下桌面敲击声 | 包括操作者及观战者在内的房间参与者 |
| 轮到本人下注行动 | 简短、明显但不刺耳的双音提示 | 当前行动者本人 |
| 新公共牌发出 | 沿用现有发牌声 | 沿用现有规则 |

全下无论由跟注还是下注／加注形成，都只播放一次筹码声。盲注、Ante、Straddle 不播放筹码声；弃牌不新增声音。奖励、派彩、补码等不属于本次下注行动音效范围。Straddle 询问、发两次牌投票和重买入不触发本人行动提示。

## 播放与个人设置

1. 沿用一个个人总静音开关，统一控制上述所有声音，保留现有本地静音选择及默认开启规则。按钮文案由“发牌音效”改为“音效”，本次不添加音量滑块或分组开关。
2. 正常连接时，每次真正轮到本人下注行动只提示一次。重复状态更新、仍未操作和进入 TimeBank 均不追加提醒。
3. 前台播放符合条件的动作声及本人提示；后台只保留本人行动提示，发牌、筹码及敲桌声静默。切回页面不补播错过的动作声，也不重复本人提示。
4. 首次进入、刷新或重连后，如果当前仍等待本人下注行动，提示一次；不重播历史动作。这是对当前待办的提醒，不是历史声音回放。此规则补充需求第 141 项的不补播原则。
5. 取消静音不补播过去的声音，也不重复当前行动提示。
6. 同次更新既有他人动作又轮到本人时，先播放短促动作声，再紧接本人提示，使两种声音清楚可辨。声音安排不得推迟按钮可用时间、服务端计时或游戏推进。
7. 音频未获浏览器播放许可、资源加载或播放失败时，牌局照常运行；不积攒过期声音等待恢复后集中播放。后台提示遵从实际浏览器运行条件，不能把代码允许后台播放当作锁屏或系统挂起时的送达保证。

## 逐项决策记录

- Q1：所有人听动作声，仅本人听行动提示。
- Q2：筹码声覆盖下注、跟注、加注、全下，排除盲注、Ante、Straddle。
- Q3：真实动作声，加清晰双音提示。
- Q4：一个总静音开关，沿用已有偏好。
- Q5：每次本人下注行动提醒一次，不新增超时或特殊询问提示。
- Q6：后台只保留本人行动提示。
- Q7：超时自动过牌同样播放两下敲桌声，弃牌无新增声音。
- Q8：首次进入、刷新、重连时仍轮到本人则提示一次；普通更新、切回、取消静音不重复。
- Q9：动作声在前，本人提示紧接其后，不影响游戏计时与操作。

## 代码核查与实现

- `src/presentation.ts` 已有共享 AudioContext、用户交互解锁、`river_muted` 偏好、发牌去重与连接基线。现有发牌声是合成噪声，没有音频素材。
- `src/main.tsx` 持有连接状态、身份和静音控制，可在房间层接入动作音效与本人行动提示。
- `backend/game.py` 的 `act()` 在服务端验证后执行行动；跟注金额为零代表过牌，超时自动过牌走独立入口。两条入口均需要产生可识别的已完成行动。
- 中文 `last_actions` 会被覆盖和清空，行动机会序号用于开始新时钟，均不能单独作为已完成行动的可靠标识。现在通过 `action_events` 提供结构化的已确认行动信息，用手号与该次行动机会序号组成稳定标识，覆盖最后一次行动和自动过牌，由保存成功后的权威状态驱动播放；不依据本地点击、中文标签或筹码余额差猜测声音。
- 客户端分别去重已完成行动和本人行动机会，建立每次连接的基线；历史动作不回放，但按 Q8 检查当前是否等待本人操作。
- 筹码与敲桌采用 CC0 真实录音素材，剪辑后分别为 300 ms、约 385 ms；来源、许可及剪辑参数见 `public/audio/README.md`。本人提示是 420 ms 的 660 Hz／880 Hz 双音。试听文件用于判断音色是否符合“真实、两下清楚、提醒明显”的要求。
- 每手只保留最近 32 个动作音效事件，公共历史接口不携带音效事件；旧房间无该字段时按空列表处理。客户端接收超过两秒的动作事件不播放，排队不无限增长；静音、失去连接、音频挂起和离开房间会停止正在播放及排队声音，后台取消动作声，行动失效取消本人提示。
- 沿用现有“下注轮”“最后行动停留”“TimeBank”等领域词汇。此项是可逆的声音呈现调整，没有需要新增的领域概念或难以逆转的取舍，不新增词条或 ADR。

## 验收标准

1. 真实本地房间中，操作者、其他玩家及观战者均能收到合法下注／跟注／加注／全下的动作声音；失败或过期命令不发声，重复提交不重复发声。
2. 手动过牌、超时自动过牌各播放一次完整的双敲声音；最后一个行动即使进入停留、投票或结算，也不漏播或重复。
3. 本人每个下注行动机会仅提醒一次；其他玩家和观战者无此提示，TimeBank、Straddle、双发投票和重买入不误触发。
4. 首次进入、刷新、重连不重播动作声；当前仍轮到本人时提醒一次。重复快照、切回前台、取消静音不重复提醒。
5. 前后台、静音及持久化偏好符合上表；后台静默的动作不会在回到前台时堆积补播。断线、离开房间或行动已失效时不继续播放排队的旧提示。
6. 连续快速行动、动作声与本人提示相邻、公共牌发出后轮到本人等组合下，提示可辨认，操作与倒计时不中断。
7. 使用后端测试验证行动标识及成功提交边界，浏览器测试验证次数、次序、去重、连接与静音规则，并运行构建及相关发牌回归。模拟音频调用通过只证明触发逻辑，不证明人耳听感。
8. 提供实际音频试听，并记录桌面及手机浏览器的实际播放验证范围；未实测的浏览器后台／锁屏行为不能记为通过。
