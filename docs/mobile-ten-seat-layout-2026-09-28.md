## 已确认规则

- 上、下各五席；底部中央为自己。图中 1–10 是视觉位置，真实座位顺序、行动和盲注轮转关系保留。人数减少时不重新排列。
- 玩家区域包含玩家框与手牌的完整可见范围。2/10 的下边界严格高于 1 的上边界；5/7 的上边界严格低于 6 的下边界。
- 所有人（含自己、亮牌、摊牌）统一由玩家框遮住手牌下部，保留两张牌的完整点数、花色和单张亮牌操作。
- 预留公共牌、底池空间，0/3/4/5 张公共牌期间所有玩家位置固定。双发仍沿用一次展示一组的既有行为。
- 有明确的最小可读尺寸，低于下限后仅牌桌区域按需横纵滚动，悬浮按钮不随滚动。
- 下注/过牌：1 在手牌上方，6 在玩家框下方；2/3 左上、9/10 右上；4/5 左下、7/8 右下。标记向桌内延伸。

## 实际尺寸与滚动

- 手机断点保持 ≤760px。牌桌内容最小 **360×800 CSS px**；最大宽度 480px，较高窗口可以增加牌桌高度。
- 玩家框统一 **104×54px**；手牌宽 **44px**、5:7 比例，向框上方露出 38px，并保留原有轻微旋转；完整玩家区域约 104×95px。点数 18px、花色 14px、昵称 14px、普通余额 16px。
- 上下各三行使用稳定锚点，两侧两行与端点一行之间有正向间距。图中位置对应真实座位的反向视觉编号，不改变顺时针游戏次序。
- 低于最小宽度时横向滚动，低于所需高度时纵向滚动，滚动由 `.room-main` 承担。另留 144px + 安全区的底部滚动余量，让底部玩家能滚动到悬浮按钮上方。
- 下注普通字号 12px；侧面大额按千分位换行，保留完整金额。宽度上限 62px；顶部/底部中央上限 104px。大额不会改变玩家位置。
- 玩家框在手牌上层；牌型标签位于框内独立底行，徽章仍沿框右上边缘横排。弃牌标记上移到露出的区域，保留实际可见性。
- 电脑端保留并排牌面与玩家框，补充第十席及对应下注/Dealer 位置。
