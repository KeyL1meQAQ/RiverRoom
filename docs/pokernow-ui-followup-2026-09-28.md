# PokerNow 风格 UI 后续对齐

状态：Q1–Q6 已确认并进入实现。基线为 `0d1d1e2`，参考用户提供的四张截图。

## 已明确的要求

- 手机将玩家集中在上、下两部分，中间为放大的公共牌保留完整空间；上下玩家、手牌与附属标记避让该空间。
- 公共牌只绘制已发出的 0/3/4/5 张，不显示空白牌面；按实际张数居中。四张或五张时下半区玩家与互动落点同步向下避让。
- 移除原操作区整体背景，以悬浮按钮呈现原有操作：手机位于画面下方，电脑位于右下角。
- 加注展开后的金额输入、快捷额度、滑杆和确认/取消也使用独立悬浮控件，不保留局部面板背景。沿用明确确认才提交的行为。
- 亮牌操作采用右下角悬浮按钮形式，包含全部与单张亮牌。
- 增大手机其他玩家的底牌显示；用户名与筹码字级、下注数额和 Dealer 标记位置对齐截图的视觉比例与所属座位关系。
- 依据追加的四张 PokerNow 局部截图，手机下注筹码按上排、上侧、中间两侧、下排两侧和本人分别贴近各自手牌/名牌；本人筹码在手牌上方留白，中间两侧筹码靠名牌上沿。大额下注可错位避免互相覆盖。
- 删除名牌 `+N` 获胜数额胶囊，使用现有飞筹码和余额翻页动画；保留派彩顺序。本项覆盖上一轮需求第 159 项恢复该胶囊的约定。
- 删除底栏重复的本人信息，不再为 BANK 数值提供额外显示入口；原有 TimeBank 计时机制不因本项改变。
- 玩家需要重买入时自动弹出金额输入弹窗，提供重买入或离座观战，不再要求先点击底栏的重买入入口。

## 重买入弹窗规则

- “离开”在此处具体执行离座观战：释放座位，留在房间观看；按钮标为“离座观战”，避免与保留座位的“离开”混淆。
- 派彩展示完成且本人属于待重买入玩家时立即弹出模态窗口。弹窗中不放亮牌按钮，弹窗显示时右下亮牌组不出现；原服务端 5 秒亮牌窗口计时照常结束，不延长。其他玩家的亮牌入口不受影响。
- 弹窗无关闭按钮，不响应遮罩点击或 Escape。输入金额确认后等待房主审批；未批准时可取消申请再填金额，也可离座观战。到账、离座或服务端 20 秒到期自动离座后自动消失。

## 已核对的现有约束

- 手机固定九席、本人位于底部，现有座位配置为上四下五；原实现存在多层 CSS 定位覆盖，中间空间并未作为完整避让区域。
- 重买入依据整手派彩及附加收付后的余额判定，全下期间的临时零余额不触发。
- 派彩展示完成后，5 秒亮牌与最多 20 秒重买入等待同时开始；普通玩家需房主审批到账，房主本人自动批准。到期仍为零筹码的玩家自动离座。
- 旧版重买入使用手动打开的补码弹窗，提交后关闭；新弹窗在审批期间继续显示，已有待审批申请禁止重复提交。
- 布局改动还需同步互动动画落点和派彩目标位置，保持既有规则及身份映射。
