# 鱿鱼模式与倍率规则在轮次边界切换

普通鱿鱼与无限鱿鱼的发放和结算条件不同，无限倍率也会改变已有标记的应收价值；用户在 2026-09-29 的 Q1、Q13 明确选择模式及倍率开关下一轮生效，接受等待本轮结束，以保留同一轮的规则一致性。它们不能跟随基础单价、亮牌及关闭玩法的下一手设置一起切换；关闭仍可按已确认规则作废未完成轮次。

无限轮次的参与资格与总量独立：新人首次实际发牌即加入本轮收付，但开轮确定的 N＋3 总量不随人员增减而改变，下一轮才重新计算（Q14）；离座责任继续遵循 ADR 0006。轮次保存与恢复须保留其模式、倍率规则和总量，普通模式的单标记兼容处理不得压缩无限模式的合法累计数量。

这些领域决策已确认，Q1–Q19 的设计分支已全部完成；完整方案已获用户最终实施确认，详见 docs/infinite-squid.md。
