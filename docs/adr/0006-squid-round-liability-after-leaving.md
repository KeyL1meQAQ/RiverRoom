# 鱿鱼轮次责任独立于当前座位

鱿鱼跨越多手牌，允许新人加入本轮并增加标记，同时允许已有参与者在轮中离座。为避免释放座位就免除付款或丢失应收奖励，本轮参与资格、标记和收付责任独立于当前座位保留，离座不减少本轮标记总数；该规则已由用户在 Q5、Q8 明确确认。

离座者剩余筹码暂留至本轮完成收付，再全额买出；接受延迟买出的成本，换取无需禁止离座、无需按未定的轮末结果提前结算。暂留筹码仍计入持有筹码与净输赢，不记为新的买入，也不能在释放座位时重复买出。每名付款者独立按自身余额支付，短缺不转嫁给其他付款者；实际支付按收款人的应收比例分配，保持筹码守恒。

取消轮次、恢复入座和无人可继续时的细则已在 `docs/squid-game.md` 的 Q14–Q16 确认：同身份恢复原筹码不重复买入，暂停和人数不足保留责任，关闭玩法或结束房间作废未完成轮次并释放暂留筹码。
