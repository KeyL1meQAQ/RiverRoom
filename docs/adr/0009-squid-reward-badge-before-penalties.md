# ADR 0009：鱿鱼轮次徽章先于罚金结算

## 状态

已接受

## 决策

一轮鱿鱼完成后，牌局结算时间线在 `squid_at` 展示服务器定时的轮次徽章 3 秒。徽章列出每位参与者的鱿鱼数量，以及数量乘以本轮单价得到的奖金；展示结束后才开始鱿鱼罚金转账动画。

徽章直接读取已提交的 `SquidSettlement.results`，不从当前玩家余额推导，也不在刷新或重连时创建新事件。取消轮次不展示奖励徽章。

## 原因

鱿鱼数量和奖金是轮次结算结果的一部分，必须在实际扣款前让玩家能读懂；由服务端时间线延迟转账可以保证所有客户端保持相同顺序，并保留余额动画的既有一致性。

## 2026-09-29 无限鱿鱼修订

Q19 确认继续使用本轮次徽章展示获得的鱿鱼数量、个人倍率和最终奖金，取消逐手获鱿鱼提示。上文“数量乘以本轮单价得到的奖金”由此修订取代：每名零标记者分别按数量 × 基础单价 × 个人倍率付款，最终奖金为所有付款者实际转账之和，可能因余额不足低于应收；徽章取已提交结算记录的实收，详情保留应收及转账明细。既有 3 秒展示时序、刷新/重连不重播、作废不展示的约定继续适用。
