# 投票结束后公开跑马底牌并显示单独获胜概率

## 背景

全下后，参与者需要在公共牌继续发出前判断局势。现有牌桌在进入 `runout` 投票阶段时就会公开未弃牌底牌，但没有提供概率提示；同时，“有人全下”不能作为跑马入口，因为其他玩家可能仍有跟注、加注或弃牌行动。概率若按底池金额或分池资格计算，也会把牌型强弱和筹码分配混在一起。

## 决策

把跑马定义为有人全下、下注行动彻底结束后开始发剩余公共牌的阶段。投票期间不因跑马提前公开对手底牌，所有投票完成或超时后，才向房间内所有人公开未弃牌跑马玩家的底牌，并开始显示概率；本人仍可查看自己的底牌。无须投票的单次跑马直接在进入跑马时亮牌和显示概率。

概率只比较所有未弃牌跑马玩家的牌型，忽略主池、边池和金额。按服务端掌握的全部已用牌排除所有玩家的已发底牌（包括弃牌者及未公开底牌）、已烧牌和已发公共牌，忽略剩余牌堆顺序，精确枚举补齐当前牌组的所有组合。未来尚未到发牌时点的牌不提前排除，也不按实际顺序固定。某玩家只有在某组合中成为唯一最佳牌型时才计一次胜出，平分的玩家均计为零。

发两次牌时只显示当前正在发出的牌组，第二组计算排除第一组已发非共享公共牌，公共前缀只计算一次。按每张公共牌亮出更新整数百分比，数字使用短动画；非零且不足 1% 显示 `<1%`，大于 99% 但未达 100% 显示 `>99%`，避免把微小概率误写成不可能或必然。当前组河牌完成并进入结果时隐藏概率，第二组开始时重新显示；底牌仍按本手公开状态保留到既有亮牌窗口结束。

所有玩家和观战者看到相同概率。桌面与手机端、自身与对手均在两张底牌整体的右上角放置小胶囊，轻微压住牌边并避开点数与花色。按精确独赢概率判色：最高者为绿色，并列最高者均为绿色，其余玩家统一为红色；所有人概率相同（包括全部为 0%）则统一中性色。判色使用实际目标概率，不使用显示舍入值或数字动画中间值。

## 原因

手机端保留底牌原有样式和点数、花色位置，避让只调整概率胶囊的大小和位置，这是用户对视觉实现的明确约束。

该顺序把亮牌时点放在投票结束后，让所有参与者在真正开始跑马时看到相同结果。用户明确选择用服务端实际剩余牌计算，因此未公开的弃牌与烧牌也影响概率；这与仅根据桌面公开信息计算的口径不同。统一对手集合和单独获胜概率避免把边池金额误读为牌力，平分记零与用户明确选择的含义一致。服务端阶段决定公开和概率目标，客户端只负责平滑呈现，因此刷新、重连和多视角不会改变牌局。

## 影响

跑马阶段会比普通摊牌更早公开底牌，这是有意选择的桌面信息规则；普通下注、普通摊牌和自愿亮牌仍沿用原有公开边界。服务端需要提供与每次公共牌展示时点一致的精确概率，前端根据当前组和目标百分比支持恢复与动画。暗底牌和烧牌参与服务端计算，但不作为新增公开牌数据发送。所有独赢概率之和可能小于 100%，概率为 0% 的玩家仍可能赢得边池。该概率只用于展示，不参与下注、投票、派彩或任何账目计算。
